# portfolio

My data analyst portfolio site. It shows my projects with their charts, SQL and screenshots.

It's a single static page: `index.html` plus the images in `img/`. No build step. Open `index.html` in a browser, or host the folder anywhere (GitHub Pages, Vercel, Netlify).

The analysis code for every project is in [data-analyst-portfolio](https://github.com/midexol/data-analyst-portfolio).

My older developer portfolio (Next.js) is on the [`dark-nextjs-site`](https://github.com/midexol/portfolio/tree/dark-nextjs-site) branch.
